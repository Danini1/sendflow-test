# Sendflow — Web

Frontend do Sendflow (React + TypeScript + Vite, Material UI + Tailwind CSS).

Documentação completa — arquitetura, modelagem, isolamento entre clientes, como rodar e testar — no [README da raiz](../README.md).

```bash
npm install
npm run dev     # requer web/.env.local (ver README da raiz)
npm run build
npm run lint
```
